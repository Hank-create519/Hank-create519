## 🔥 我的项目

### [Hank Agent Team](https://github.com/Hank-create519/Hank-Agent-Team) — 多 Agent 协作流水线引擎

桌面端 AI 团队模拟器：四个 AI 部门（指挥部 / 信息部 / 开发部 / 审核部）自动分工协作，经历 8 阶段标准化流水线与双重审查打回，最终交付可部署成果。

- 🏭 四部门协作 + 八阶段流水线（方案 → 审查 → 编码 → 部署 → 交付）
- 🛡️ L1~L5 五层安全纵深防御，按部门分配工具权限
- 🤖 47 个预置模型，覆盖 14 家 LLM 厂商，Agent 级独立配置
- 🖥️ Electron + React + TypeScript 跨平台桌面端

### [HankAI-Review](https://github.com/Hank-create519/HankAI-Review) — 瀚海AI审查系统

多智能体辩论式学术评审框架：8 个 AI Agent 分工协作，通过多角色辩论机制完成文献的搜集、筛选、评审与存档。

- ⚖️ 辩论式评审：3 个评审 Agent 对抗辩论 + 裁判 Agent 仲裁 + 双重整合
- 🔍 全流程自动化：文献检索 → 关键词生成 → 自动下载 → PDF 解析 → 结构化综述
- 🧠 Agent 行为宪法（AI Constitution）+ 安全防护 + 工具调度
- 🖥️ Electron 42 + React 19 + SQL.js 本地数据库
